# Android LCM Detection

</div>


## Introduction

This project is a tool to detect the screen of Android devices using LCM (Local-Contrast-Measure).


## Usage

1. Connect your Android device to your computer with a USB cable.
2. Run the app and import excel file which contains the ADB commands to the table.
3. Run the ADB commands in the table and get the LCM detection result.
4. The result will be saved to local and can be checked in UI.


## Requirements

- Android device which support ADB
- Excel file with LCM information and ADB commands


## Features

- Frontend-Backend separation
- Database integration
