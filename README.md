# Android Screen Defects Detector

A tool for detecting the screen defects of Android devices.

</div>


## Usage

1. Connect your Android device to your computer with a USB cable.
2. Run the app and the detection will automatically start.
3. The result will be saved to local and can be checked in UI.


## Requirements

- Android device which support ADB
- PC device with CUDA
